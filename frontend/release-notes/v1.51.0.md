# What's New in Version 1.51.0

**Released:** November 16, 2026

---

## ✨ New Features

### Edit a task

An administrator, a Personnel Contact or Assistant, or the person who submitted a task can change it.

**What you can do:**
- Change the title, detail, timing, and due date
- Change the project, the assignee, and the requestor

**How to use it:**
1. Open Work.
2. Choose Edit on the task.
3. Change what you need, then choose Save changes.

From My Work, Edit opens the same form on Work.

### See the due date

When a task has a deadline, the date is labeled as the due date on the task. The published date is still the day the task was added.

---

## 💡 What You Need to Know

- No action is required.
- A crew request or a process keeps its timing when you edit it.
- The phone Help article mentions a due date. Install the new store build to read that wording.
