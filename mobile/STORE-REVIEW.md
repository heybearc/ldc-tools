# Store review packet

Use this when submitting `com.ldctools.mobile`. The privacy policy and support form must be on the live site (`https://ldctools.com/privacy` and `https://ldctools.com/support`) before review, not only on standby.

Create one real demo account on production before you submit. Put that email and password in both review forms. Leave the server at `https://ldctools.com`. Do not delete that account while a review is open.

## App Store Connect

- Privacy policy URL: `https://ldctools.com/privacy`
- Support URL: `https://ldctools.com/support`
- Sign-in required: yes
- Demo account: the production user you created for review
- Notes:

```
LDC Tools is invite-only for one construction group. There is no public signup.
Sign in with the demo account above. Leave the server at https://ldctools.com
(the Server row is optional and can stay closed).

The app shows that group's work, projects, processes, trade teams,
directory, feedback, and private chat. Admins also get account roles,
announcements, and the feedback queue. Mail settings and backups stay
on the website.
Users can report a chat message and block a person. Reports are emailed to
the group's administrators and filed in the admin feedback queue.
Account deletion is on My Work: Delete account. It disables that sign-in
and removes the password. Group records the organization already keeps stay
with the group.

The app can open the photo library to replace a directory profile photo.
It does not use the camera, location, device contacts, ads, or tracking.
Encryption is only standard HTTPS.
```

- Age rating: 12+ / infrequent profanity possible, because members can type chat freely. No unrestricted web, no made-for-kids.
- Screenshots: iPhone, and iPad as well, because tablet support is on.
- Export compliance: uses only exempt HTTPS. Already set in the app.

Privacy nutrition labels, data linked to the user, not used to track, not shared:

- Contact info: name, email, phone
- Photos: profile photos the group stored, including a photo chosen from the library to replace one
- User content: chat messages
- Identifiers: user id

## Play Console

- Privacy policy: `https://ldctools.com/privacy`
- App access: all functionality is restricted. Provide the same demo login. Credentials stay valid.
- Ads: no
- Target age: 18 and over. Not designed for children.
- News app, government, financial: no
- Data safety: data is encrypted in transit. Users can request deletion in the app. Data is not sold. Data is not shared with third parties.

Declare these as collected, required for app functionality, and linked to the account:

- Name, email address, phone number, user id
- Photos (profile photos already stored for the group, and a photo chosen to replace one)
- Chat messages

Do not declare location, contacts from the device, financial info, or device advertising id.

The release app can ask for photo library access when someone replaces a directory photo. It does not request broad storage, camera, or display-over-other-apps permissions.

A new personal Play account may have to keep a closed test with 12 testers for 14 days before production access opens.

## Listing text

Short description:

```
Invite-only work, projects, directory, and chat for your construction group.
```

Full description:

```
LDC Tools is invite-only. Downloading it does not create an account.

Signed-in members of a construction group can see their work, projects,
processes, trade teams, the group directory, and private chat. They can
update a directory photo, send feedback, and, when their role allows,
edit projects and start processes. Administrators can manage accounts,
announcements, and feedback. To request access, contact the
person who runs your group or use https://ldctools.com/support.

An administrator creates your account. You can delete that sign-in
inside the app. The privacy policy is at https://ldctools.com/privacy.
```
