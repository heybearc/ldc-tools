# What's New in Version 1.39.0

**Released:** October 30, 2026

---

## ✨ New Features

### Import crew requests

On Work, Personnel can import the crew-update spreadsheet. Each row becomes a claimable task with the volunteer, crew, project roster, comments, and the person who asked. Importing the same spreadsheet again does not add those rows twice. When the task is marked Done, the requestor stays on it. If email is already set up, they are told it is done.

---

## 💡 What You Need to Know

- Use the spreadsheet from the crew-update form
- The task is claimable, so someone on the construction group can take it
- Help for this is on the Work page in the Help Center
