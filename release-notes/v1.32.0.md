# What's New in Version 1.32.0

**Released:** October 29, 2026

## Work list

Open Work in the menu. The list is only for the construction group you are signed in to.

- Personnel can add a task and assign it to someone in the group
- Mark a claimable task so anyone signed in here can take it
- See a deadline, a date on a project, or a monthly or yearly repeat on each row

## What you need to know

A task from another construction group does not appear here. Claiming a task assigns it to you.
