# What's New in Version 1.48.1

**Released:** November 8, 2026

---

## ✨ New Features

### Mark a chat unread

Next to each conversation you can choose Mark unread or Mark read. The Chat link shows how many conversations still need you.

---

## 🐛 Bug Fixes

### Sign-in matches LDC Tools

The sign-in page shows the LDC Tools logo and says what you can open after you sign in. There is no server choice on that page.

### Accounts are the people who sign in

Admin Accounts lists sign-in accounts for this construction group: Personnel, admins, and people you invited. Directory contacts stay in the directory.

### Saving a project confirms what you saved

After you choose Save project, a note names the project and its status. A project can be marked cancelled.

- No action required
- People who already sign in use the same account
