# What's New in Version 1.55.0

**Released:** November 18, 2026

---

## ✨ New Features

### Start a task, then mark it finished

Open work now asks you to start it before you can finish it. The button says Start, then Finished. An admin, an overseer, an assistant, the person who claimed it, or the assigned person can use it. Support can use it only when the work is assigned to them.

**How to use it:**
1. Open Work, My Work, or the task on your phone.
2. Choose Start when you begin.
3. Choose Finished when the task is done.

If the work is assigned to someone else, or returned to the pool, the next person sees Start again. Mark selected finished only includes tasks that have already been started.

---

## 🐛 Bug Fixes

### Chat stays where you left it

A refresh that finds no new messages no longer jumps the conversation.

---

## 💡 What You Need to Know

- The task stays open until you choose Finished.
- The phone app shows Start and Finished after this store update. Until then, an installed phone may still show Done.
- No other action is required.
