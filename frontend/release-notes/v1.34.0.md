# What's New in Version 1.34.0

**Released:** October 30, 2026

---

## ✨ New Features

### Dates on a project

Open Projects. Each project has a schedule.

**What you can do:**
- Personnel can add a title, detail, and date
- See that date on the project
- See the same date on the work list

**How to use it:**
1. Open Projects
2. Find the project
3. Enter a title, detail, and date
4. Choose Add date

## 💡 What You Need to Know

- The date belongs to this construction group
- Marking it Done on the work list marks it Done on the project
- This is not the old trade-crew calendar
