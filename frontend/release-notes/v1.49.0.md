# What's New in Version 1.49.0

**Released:** November 11, 2026

---

## ✨ New Features

### Process templates can stay drafts

A new process is a draft until you publish it. Drafts stay on the Processes page for Personnel. They do not show up as available work, and they cannot be started. Publish when the tasks are ready. You can return a published process to draft later. Saving changes does not change whether it is a draft or published.

### Choose where it runs, and how often

Each process is standalone, or it belongs on a project. The schedule is separate: one time, daily, weekly, every two weeks, monthly, quarterly, yearly, or a custom number of days, weeks, or months.

Starting a published process adds one work item. The tasks stay inside that item. The schedule is a reminder of how often the work should happen. You start the next one yourself when it is time.

**What you can do:**
- Save a process as a draft and come back to it
- Publish it for the construction group
- Add a project process to a project, or claim a standalone process from Work
- See the schedule on the work item

**How to use it:**
1. Open Processes and enter the name, what it is for, and the tasks.
2. Choose Standalone or Project, and choose how often it should be done.
3. Save the draft. Publish it when it is ready.
4. Add it to a project, or claim it from Work.

The phone app has the same choices. Install the new store build to use them there.
