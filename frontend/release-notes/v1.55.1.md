# What's New in Version 1.55.1

**Released:** November 25, 2026

---

## 🐛 Bug Fixes

### The message box stays on screen

Chat fills the window under the header. The list of messages scrolls inside the conversation. The box where you type stays at the bottom. It grows a few lines as you type. Press Enter to send. Press Shift+Enter for a new line.

### A web address in a message is a link

An address in a chat message opens when you choose it. Pasting a linked title keeps the address with the title. The phone app opens an address in a message the same way.

## 💡 What You Need to Know

- No action required
- Open Chat and the message box is at the bottom of the window
