# What's New in Version 1.43.0

**Released:** October 31, 2026

---

## ✨ New Features

### Tablet layout

On a tablet, the app shows My Work and the directory at the same time. A phone still uses two tabs.

---

## 🐛 Bug Fixes

### Clearer failures

When a page cannot load, it says what failed and asks you to try again. When the session has ended, it asks you to sign in again.

---

## 💡 What You Need to Know

- No action is required.
- Reload the app on a tablet to see both lists.
