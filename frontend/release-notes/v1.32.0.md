# What's New in Version 1.32.0

**Released:** October 29, 2026

---

## ✨ New Features

### Work list

Open Work in the menu. The list is only for the construction group you are signed in to.

**What you can do:**
- Personnel can add a task and assign it to someone in the group
- Mark a claimable task so anyone signed in here can take it
- See a deadline, a date on a project, or a monthly or yearly repeat on each row

**How to use it:**
1. Open Work
2. Choose Add work
3. Enter the title and detail, then choose the timing
4. Assign someone, or leave it claimable and unassigned
5. Save

## 💡 What You Need to Know

- A task from another construction group does not appear here
- Claiming a task assigns it to you
- Mark it Done when the work is finished
