# What's New in Version 1.46.0

**Released:** November 3, 2026

---

## ✨ New Features

### Edit a project

Open Projects and choose Edit project. You can change the name, number, location, status, start, end, and Builder Assistant link. Choose Remove to take the project off this list. Dated work stays on the work list.

### See dates on a calendar

Projects can stay as a list, or you can choose Calendar. Day, Week, and Month move through the start dates, end dates, and schedule dates.

### Projects in the phone app

The LDC Tools app has a Projects tab. It shows this construction group's projects, who is assigned, and the schedule. The store build is 1.0.2.

---

## 🐛 Bug Fixes

### Chat stays above the keyboard

On the phone, the message box stays visible while the keyboard is open.
