# What's New in Version 1.36.0

**Released:** October 30, 2026

---

## ✨ New Features

### Add a project

Personnel and a super admin can add a project for this construction group.

**What you can do:**
- Add a project with a name
- Include a number and location when you have them

**How to use it:**
1. Open Projects
2. Choose Add project
3. Enter a name
4. Choose Save project

---

## 🐛 Bug Fixes

### Stay in your construction group

Work and Projects open for the construction group you serve in. A super admin is in that group unless they choose another one.

**What you can do:**
- Add work from the Work page
- Open Admin and go straight to the Admin Control Center
- Manage the Personnel team for this region, including edit and delete

---

## 💡 What You Need to Know

- Choose a construction group in the header when you want a different group
- All Construction Groups is for looking across groups. Work and Projects need one group
