# What's New in Version 1.49.1

**Released:** November 14, 2026

---

## ✨ New Features

### Start a chat the way you start one in Teams

Chat lists the conversations you already have. Team chat stays at the top. To message someone new, choose New chat. Search by name or email, or choose the person from the list. The rest of the Personnel team stays out of the conversation list until you start that chat.

**What you can do:**
- Find an open conversation
- Start a direct message from search
- Start a direct message by choosing a person

**How to use it:**
1. Open Chat.
2. Choose New chat.
3. Search for a name, or choose a person from the list.
4. Type the message and choose Send.

The phone app has the same New chat control. Install the new store build to use it there.

---

## 💡 What You Need to Know

- Team chat still goes to the Personnel team
- A direct message is still only between the two of you
- Turn on notifications once on each phone or computer
