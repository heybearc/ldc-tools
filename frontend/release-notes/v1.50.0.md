# What's New in Version 1.50.0

**Released:** November 15, 2026

---

## ✨ New Features

### See when work was published

Each task shows the date it was added. Each process shows the date it was saved, or the date it was published. Choose Newest or Oldest to put the list in date order.

**What you can do:**
- See the date on a task
- See the date on a draft or a published process
- Sort the list newest first or oldest first

**How to use it:**
1. Open Work or Processes.
2. Look for the date next to the title.
3. Choose Newest or Oldest.

The phone app shows the same dates on My Work, Available work, and Processes. Install the new store build to use the new Help articles and the date sort there.

### Read Help as articles

On the phone, Help is a list of topics. Open a topic to read the full article, including work, processes, the directory, chat, alerts, feedback, and admin.

---

## 🐛 Bug Fixes

### The completion email names the task

When a task is finished, the email subject is the task title. “Crew request completed” is used only when the finished item is a crew request.

### Admin accounts stay highlighted

On the phone, an admin account shows Admin as selected. Marking feedback In progress or Resolved saves that choice. Feedback items show their FB number on the website and on the phone.

### Saving a directory photo

Replacing a picture no longer stops because the same Trade Crew Overseer role is already on that crew.

## 💡 What You Need to Know

- Install the new phone build to see Help articles, publish dates, and the admin fixes on the phone
- The website shows publish dates as soon as this version is live
