# What's New in Version 1.44.0

**Released:** November 3, 2026

---

## ✨ New Features

### Available work

The LDC Tools app has an Available tab. It lists claimable work that nobody has taken. Choose Claim and that work moves to My Work.

### Directory sections

The directory opens on Construction group, Personnel, Ancillary, or a trade team. After a trade team, choose the team itself or one crew. The list shows only those people.

### A person's profile

Tap a name to see the role, the place, and the photo when one is on file. Tap the email to write to them. Call or text when a phone number is listed.

### App icon

The phone app uses the LDC Tools logo.

---

## 💡 What You Need to Know

- Install the updated app when it is available from the store.
- On a tablet, My Work and the directory still sit side by side.
