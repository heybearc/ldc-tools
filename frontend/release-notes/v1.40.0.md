# What's New in Version 1.40.0

**Released:** October 30, 2026

---

## ✨ New Features

### No deadline

When you add work, choose No deadline. The task stays on the list without a date.

### Assign several tasks

Select the open tasks you want, including a range with Shift, choose one person, and assign them together.

---

## 🐛 Bug Fixes

### The group you already chose

Work now lists tasks for the construction group shown in the header. You do not have to pick that group again.

---

## 💡 What You Need to Know

- Claim is still one task at a time, so the rest stay available for the group
- Help for this is on the Work page in the Help Center
