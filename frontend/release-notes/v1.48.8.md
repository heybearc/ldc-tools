# What's New in Version 1.48.8

**Released:** November 11, 2026

---

## 🐛 Bug Fixes

### Completion email matches the tasks you selected

On Work, select several tasks and choose Email off or Email on. Each selected task's "Email the requestor when this is done" box now matches that choice. The confirmation names how many tasks changed.

### Chat lists everyone in the group

Message one person lists everyone signed in to this construction group. Turn on notifications in the browser when you want that computer to be told about a new message. Each phone and computer does this once.

### Every Personnel person can be assigned to a project

The project assignment list includes every Personnel person in this construction group.

---

## 💡 What You Need to Know

- No action is required.
- A Bethel or jwpub.org address still cannot be emailed.
- The installed phone app reads these chat and project updates. A new store build is not required for this release.
