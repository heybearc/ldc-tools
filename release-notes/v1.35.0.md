# What's New in Version 1.35.0

**Released:** October 30, 2026

---

## ✨ New Features

### Processes

Save a checklist for this construction group. Starting it puts each step on the work list.

**What you can do:**
- Add a process with a name and steps
- Add an explanation or a reference link on a step
- Start the process, with a project when you choose one
- See those steps on the work list

**How to use it:**
1. Open Processes
2. Enter a name and each step
3. Choose Save
4. Choose Start

### Personnel on the directory

Personnel Contact, Assistant, and Support have their own card.

**What you can do:**
- Find Personnel without looking through the construction group
- See the construction group overseer, assistant, and support on the Construction group card

**How to use it:**
1. Sign in. The dashboard opens.
2. Open Directory
3. Look at Construction group, then Personnel

## 💡 What You Need to Know

- A process belongs to the construction group you are signed in to
- The Construction group card is the construction group itself
- No action is required
