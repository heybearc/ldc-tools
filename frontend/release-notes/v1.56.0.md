# What's New in Version 1.56.0

**Released:** November 27, 2026

---

## ✨ New Features

### References

References is a shared list of links for your construction group. Open it from the header on the website, or from More in the phone app. Personnel Contact, Assistant, and Support can add, edit, and remove a link. Everyone signed in can search and open it.

**What you can do:**
- Save a form, a document, or a site
- Group links by category
- Find a link from the website or the phone

**How to use it:**
1. Open References.
2. Search, or choose a category.
3. Open the link. Personnel can add a new one with Add link.

### The whole group hears about waiting work

When work is claimable and nobody has it yet, everyone signed in to the group gets an email, a phone alert, and a browser alert. The message names the task or process and links to LDC Tools. A crew-request import does the same. The person who made the work available is not included.

When someone else assigns work to you, you get the same email, phone alert, and browser alert. Taking the work yourself does not send that message.

The email comes from LDC Admin Team.

## 🐛 Bug Fixes

### The header and the message box stay on screen

References fits in the header without pushing the page sideways. On Chat, the message box stays at the bottom of the window.
