# What's New in Version 1.33.0

**Released:** October 29, 2026

---

## ✨ New Features

### Projects

Open Projects in the menu. The list is only for the construction group you are signed in to.

**What you can do:**
- See each project's name, status, number, location, and dates
- Oversight can assign Personnel to a project and remove them
- Open Builder Assistant when a project has that link

**How to use it:**
1. Open Projects
2. Find the project
3. If you are oversight, choose a person under Add Personnel and choose Assign
4. Choose the × next to a name to remove that person

## 💡 What You Need to Know

- A project from another construction group does not appear here
- Crews, budget, and congregations are not on this list
- Opening a single project returns you to the list
