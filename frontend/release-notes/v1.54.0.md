# What's New in Version 1.54.0

**Released:** November 17, 2026

---

## ✨ New Features

### Install the phone app from the website

Sign in on the website, then open Mobile app. One page has the install link for iPhone and iPad, and the install link for Android.

**What you can do:**
- Open the page from the dashboard, Help, or the footer
- Install the test app on the phone you use
- Sign in on the phone with the same account

**How to use it:**
1. Sign in at ldctools.com.
2. Open Mobile app.
3. Choose Download on the App Store, or Get it on Google Play.
4. On the phone, sign in with your LDC Tools account. Leave the server at ldctools.com.

---

## 💡 What You Need to Know

- Downloading the app does not create an account.
- On Android, use the Google account that was added to the test.
