# What's New in Version 1.45.0

**Released:** November 3, 2026

---

## ✨ New Features

### Open a claimed task

After you claim work, open it. Check off each step as you finish it. Choose Done when the whole task is finished.

### Return work to the pool

If you cannot get to a task you claimed, choose Return to pool. Someone else in the group can claim it.

### Chat in the phone app

The app has a Chat tab. The team room is there, and you can message one person.

---

## 🐛 Bug Fixes

### Starting a process

Choose a project, then Start. The project stays selected, and the page confirms that the process is on Work.

---

## 💡 What You Need to Know

- Install the updated app when it is available from the store.
- On a phone, website chat shows the list until you open a conversation.
