# What's New in Version 1.41.0

**Released:** October 30, 2026

---

## ✨ New Features

### Chat

Open Chat to message everyone in this construction group, or start a conversation with one teammate.

### My Work

Your assigned tasks are on My Work. The dashboard still shows a short list of them.

### Replies on a help request

When someone asks for help on a task, you can reply on that request. A new reply stays unread until you open it.

### Finish several tasks

Select the open tasks you want, including a range with Shift, and mark them done together.

---

## 🐛 Bug Fixes

### Who is emailed

A help request goes to the Personnel Contact and Assistant. A Bethel or jwpub.org address is not emailed.

### The requestor stays on a finished task

Marking a crew request done still shows who asked for it.

---

## 💡 What You Need to Know

- Chat is only for the construction group you are signed in to
- Help for chat is in the Help Center
