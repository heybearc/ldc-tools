# What's New in Version 1.54.2

**Released:** November 17, 2026

---

## 🐛 Bug Fixes

### Announcement actions stay on screen

On the Announcements page, Edit and Delete were cut off at the right edge. Those actions now stay visible, and the rest of the admin area uses the width of the window.

**How to use it:**
1. Open Admin Control Center.
2. Choose Announcements.
3. Use Edit or Delete on the right side of each announcement.

---

## 💡 What You Need to Know

- No action is required.
- Creating and editing announcements works the same way.
