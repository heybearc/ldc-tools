# What's New in Version 1.37.0

**Released:** October 30, 2026

---

## ✨ New Features

### Open a profile from the directory

Click a name under Construction group, Personnel, or Ancillary. Their profile opens so you can update the name, email, phone, photo, role, and dates.

**What you can do:**
- Open the profile from the person's name
- Save changes without choosing a trade or crew

**How to use it:**
1. Open Directory
2. Click the person's name
3. Update the profile and save

---

### Correct a user account

An administrator can change the name and email on a user, and can cancel an invitation that has not been accepted.

**What you can do:**
- Edit the name and email before you save
- Cancel an invitation so it cannot be accepted
- See how many people are inactive

**How to use it:**
1. Open Admin, then User Management
2. Choose the pencil, update the name or email, and choose Update User
3. For an invited person, open More actions and choose Cancel Invitation
