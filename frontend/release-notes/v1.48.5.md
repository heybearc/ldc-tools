# What's New in Version 1.48.5

**Released:** November 11, 2026

---

## 🐛 Bug Fixes

### Creating an account works again

When you create a sign-in account, you choose platform access: User, Admin, Super Admin, or Read Only. The form no longer asks for an organizational role, and creating the account no longer fails.

Organizational roles, such as Zone Overseer or Personnel Contact, are still assigned on the volunteer record.

---

## 💡 What You Need to Know

- No action required for existing accounts
- Create a new account from Admin → Accounts → Create User
- Invite someone the same way as before
