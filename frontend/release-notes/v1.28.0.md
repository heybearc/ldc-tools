# What's New in Version 1.28.0

**Released:** October 27, 2026

---

## ✨ New Features

### Trade Leadership Directory

The app opens on the trade directory. Empty duplicate trades are no longer shown.

**What you can do:**
- Search by trade, person, or role
- Copy an email from the directory
- Add a person to a trade or crew
- Edit a person's name, email, phone, role, and dates
- Set an end date to deactivate someone without dropping them from the list

**How to use it:**
1. Open LDC Tools. You land on the directory.
2. Click a person to edit them, or choose Add person.
3. To end service, set an end date and save. They stay visible, marked ended, until a replacement in that same role is added with a start date.

Older tools such as volunteers and projects are under More.
